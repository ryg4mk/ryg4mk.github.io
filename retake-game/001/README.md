# 猫の手も借りたい RETAKE #001

ONE TAKE GAME #001「猫の手も借りたい」を、ルールを増やしすぎず遊び直しやすくブラッシュアップしたRETAKE版です。

## RETAKEポイント

- 6個の物の初期位置を毎回ランダム化
- ゴミ箱・洗濯カゴ・おもちゃ箱の並びを毎回ランダム化
- 12種類の候補から毎回6個を選出
- 3カテゴリ（ゴミ・洗濯物・おもちゃ）から各2個ずつ出現
- 物同士が近すぎる配置を避ける配置生成
- つかんだ時の浮き・影を強化
- 正しい収納時にキラキラ・縮小・吸い込み演出
- 収納成功・失敗・クリア時にWeb Audio APIの短い効果音
- 全片付け時に「おかたづけ完了！」演出を追加
- 難易度は1種類のみ
- 評価ランク、ミス数、連続ボーナスなどの追加ルールはなし

## 遊び方

1. スタートを押すと3→2→1で開始します。
2. 指またはマウスで猫の両手を動かします。
3. 両手の間に物を入れると自動でつかみます。
4. ゴミはゴミ箱、洗濯物は洗濯カゴ、おもちゃはおもちゃ箱へ運びます。
5. 6個すべて片付けたタイムを競います。
6. もう一回遊ぶたび、物・配置・収納場所の並びが変わります。

## 技術

HTML / CSS / Vanilla JavaScript / Canvas 2D / Pointer Events / Web Audio API。
外部素材・外部ライブラリ・ビルド工程はありません。
