RETAKE #001

猫の手も借りたい

猫の両手で6個の物を正しい場所へ片付けるタイムアタックを、毎回遊び直せる形にブラッシュアップ。 物・配置・収納場所の並びが変わり、触った時と片付けた時の演出も強化しました。

ONE TAKE版からの変更点

毎回同じ6個・同じ配置だった構成を、12種類から6個を選ぶランダム制に変更。物の初期位置と収納場所の並びも毎回変わるようにし、アイテムを見分けやすい絵文字表示へ変更。収納時・クリア時の演出と効果音も追加しました。

RETAKE #004

文字サーキットレース

好きな1文字がそのままマシンになる3周レースを、より速く、追い越しやすくブラッシュアップ。 BOOSTの爽快感を強め、減速要素を減らした高速版です。

ONE TAKE版からの変更点

通常速度を高速化 / BOOSTを大幅強化 / コーナー減速を撤廃 / SLOW床を撤廃 / 接触時の減速をなくし追い越し補助を追加 / 対車両の当たり判定を縮小
