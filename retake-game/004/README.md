# 文字サーキットレース RETAKE #004

ONE TAKE GAME #004「文字サーキットレース」を、スピード感と追い越しやすさを中心にブラッシュアップしたRETAKE版です。

## ONE TAKE版からの変更点

- 通常走行の最高速を大幅に引き上げ、レース全体のテンポを高速化
- BOOSTは文字ごとのTURBO性能で強さ・持続時間が変わるよう変更
- CPUも各3回BOOSTを使うようにして、プレイヤーだけの必勝ボタンにならないよう調整
- コーナーによる大きな自動減速を撤廃
- コース上の加速・減速パッドをすべて撤去
- 車同士の当たり判定を完全撤廃し、自由に追い越せるよう変更
- ガードレール接触時の速度低下を撤廃
- 文字性能を SPEED / ACCEL / STABILITY / TURBO に変更し、文字選びがレース結果に影響するよう強化
- 3周制・プレイヤーBOOST3回は維持

## 遊び方

1. 好きな1文字を入力します。
2. 車体カラーを選びます。
3. STARTでCPU3台との3周レース開始。
4. レース中に画面またはBOOSTボタンをタップすると加速します。1レース3回までです。
5. BOOSTの強さと持続時間は選んだ文字のTURBO性能で変わります。CPUもBOOSTを使います。
6. ゴール後に順位・タイム・ベストラップを確認できます。
