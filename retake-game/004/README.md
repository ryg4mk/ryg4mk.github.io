# 文字サーキットレース RETAKE #004

ONE TAKE GAME #004「文字サーキットレース」を、文字そのものを使ったバトルレースへブラッシュアップしたRETAKE版です。

## ONE TAKE版からの変更点

- 通常走行の最高速を引き上げ、レース全体のテンポを高速化
- BOOSTを廃止し、他車を攻撃できる「SPIN ATTACK」に変更
- プレイヤー・CPUとも、近距離で回転攻撃を使えるよう変更
- 車同士の当たり判定を弱めに復活。通常接触は軽く押し合う程度に調整
- 回転攻撃が当たると、相手の文字画像そのものが欠ける破壊表現を追加
- 文字ごとの耐久力として TOUGHNESS を追加
- 壊れすぎると BREAK してリタイア
- 回転攻撃はクールダウン制で、連打できないよう調整
- 回転中は少し速度が落ちるため、攻撃するタイミングが必要
- コーナーによる大きな自動減速を撤廃
- コース上の加速・減速パッドをすべて撤去
- ガードレール接触時の速度低下を撤廃
- 文字性能を SPEED / ACCEL / STABILITY / TOUGHNESS に変更
- 3周制は維持

## 遊び方

1. 好きな1文字を入力します。
2. 車体カラーを選びます。
3. STARTでCPU3台との3周レース開始。
4. 他の文字車に近づいたら、画面またはSPINボタンをタップして回転攻撃します。
5. 回転中に相手へ当たると文字が欠けていきます。壊し切るとBREAKです。
6. SPIN ATTACKは使用後に約2〜3秒のクールダウンがあります。
7. ゴール順位と、相手を壊すリスク・タイミングの両方を考えて1位を目指します。
