# 文字サーキットレース RETAKE #004

ONE TAKE GAME #004「文字サーキットレース」を、スピード感と追い越しやすさを中心にブラッシュアップしたRETAKE版です。

## ONE TAKE版からの変更点

- 通常走行の最高速を大幅に引き上げ、レース全体のテンポを高速化
- BOOSTの加速倍率・発動時間・押した瞬間の加速を強化
- コーナーによる大きな自動減速を撤廃
- SLOW床を撤廃し、コース上のパッドはすべて加速系に変更
- 車同士が接触しても速度を落とさないよう変更
- 接触時に後続車が横へ抜けやすくなる追い越し補助を追加
- 車同士の当たり判定を少し小さくし、文字同士が詰まりにくいよう調整
- 文字ごとの SPEED / ACCEL / STABILITY / WEIGHT、3周制、BOOST3回は維持

## 遊び方

1. 好きな1文字を入力します。
2. 車体カラーを選びます。
3. STARTでCPU3台との3周レース開始。
4. レース中に画面またはBOOSTボタンをタップすると強力に加速します。1レース3回までです。
5. コース上の加速パッドも利用して1位を目指します。
6. ゴール後に順位・タイム・ベストラップを確認できます。
